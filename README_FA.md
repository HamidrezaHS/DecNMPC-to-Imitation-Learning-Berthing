# راهنمای بسته IL برای ارسال مقاله به Applied Ocean Research

این مخزن شامل چهار کنترل‌کننده عصبی غیرمتمرکز، دو مجموعه وزن برای هر یدک‌کش، داده‌های شبیه‌سازی، نتایج شش آزمون مستقل، کد کنترل‌کننده معلم و بنچمارک محاسباتی است. نسخه IL به‌طور مستقل DOI ندارد؛ DOI قبلی فقط متعلق به Dec-NMPC مرجع است.

برای ارزیابی: ابتدا وابستگی‌ها را نصب کنید، سپس `python -m pytest -q tests tests_il` و دستور اجرای `python -m imitation.rollout` در README انگلیسی را اجرا نمایید.

در ارزیابی شش‌تایی، روش پیشنهادی ۴ موفقیت و ۲ اتمام زمان ثبت کرده است؛ دو شکست باید در گزارش باقی بمانند. نسبت زمان محاسباتی ۴۸٫۴ برابر فقط از بنچمارک ۳۶ تصمیمِ شروع مانور روی CPU به‌دست آمده است. این نسبت ادعای افزایش سرعت همه سناریوها یا تضمین ایمنی نیست.

برای انتشار GitHub: پوشه را از ZIP خارج کنید؛ LICENSE را پس از تأیید حقوق انتشار تکمیل کنید؛ مخزن تازه IL بسازید؛ پس از موفقیت CI یک Release صادر کنید؛ سپس Zenodo را متصل کرده و DOI جدید IL را در مقاله درج کنید.
